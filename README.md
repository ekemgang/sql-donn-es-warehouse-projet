# Projet d'un Datawarehouse et Analyse de données
Rendez-vous sur l'environnement du ** Projet d'un Datawarehouse et Analyse de données** !
Ce projet montre de manière simple la construction d'une solution d'entrepôt de données moderne multi-source, avec analyse et doté d'objets ETL. 
Le projet est conçu pour inspirer les bonnes pratiques en matière de data ingénierie et data analyse.
